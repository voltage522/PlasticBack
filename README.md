## О проекте

PlasticBack — MVP веб-приложения для жителей Казахстана 16–35 лет. Пользователь отмечает, сколько напитков навынос покупает в день, и видит свои расходы за год, количество упаковки и потенциальную экономию. Затем он отмечает дни без покупок в трекере, а общая статистика всех пользователей собирается анонимно в Supabase.

Язык интерфейса — русский, валюта — казахстанский тенге (₸).

## Возможности

**Калькулятор**
- Бутилированная вода (250 ₸), кофе (1 200 ₸), энергетики (650 ₸).
- Ползунок от 0 до 10 и кнопки «+» и «−» для каждого напитка.
- Расходы за день, месяц и год пересчитываются сразу.

**Итоги в стиле Spotify Wrapped**
- Годовые расходы — главный элемент экрана.
- Разбивка по напиткам, количество упаковок, номинальный объём воды.
- Комната, которая заполняется пластиком: «Чисто», «Захламлено», «По колено в пластике», «Катастрофа».
- Что можно купить на эти деньги и сколько можно сэкономить.

**Трекер экономии**
- Отметка «день без покупок» — не чаще одного раза в календарный день на устройстве.
- Накопленная экономия, серия дней, прогресс к цели 30 дней, календарь за 14 дней.
- Сброс прогресса с подтверждением.
- Глобальная статистика всех пользователей.

**Без регистрации.** Данные хранятся в LocalStorage и восстанавливаются после перезагрузки. Без Supabase сайт полностью работает локально.

## Структура

```
PlasticBack/
├── index.html            # разметка трёх экранов, шаблон строки напитка, окно сброса
├── css/
│   ├── style.css         # дизайн-система и компоненты (mobile-first)
│   └── responsive.css    # брейкпоинты 375 / 768 / 1024 / 1440
├── js/
│   ├── config.js         # цены, коэффициенты, пороги, эквиваленты, ключи Supabase
│   ├── calculator.js     # математическая модель (чистые функции)
│   ├── tracker.js        # отметки, серия, сброс (чистые функции)
│   ├── storage.js        # LocalStorage: загрузка, проверка, восстановление
│   ├── supabase.js       # RPC-вызовы, таймауты, обработка ошибок
│   └── app.js            # интерфейс и навигация между экранами
├── assets/
│   ├── icons/            # логотип, фавикон, иконки напитков и эквивалентов
│   └── images/           # иллюстрации комнаты (room-*.svg)
├── database/
│   └── schema.sql        # таблица, RLS, RPC-функции
├── CHANGELOG.md
└── LICENSE
```

Слои разделены: `calculator.js` и `tracker.js` ничего не знают о странице и хранилище, `storage.js` — о сервере, а `app.js` связывает всё с интерфейсом. Модули доступны через `window.PlasticBack` — это точка расширения, например для будущего Telegram Web App.

## Быстрый старт

Сборка не нужна. Склонируй репозиторий и запусти любой статический сервер:

```bash
git clone https://github.com/voltage522/PlasticBack.git
cd PlasticBack
python -m http.server 8080
```

Открой http://localhost:8080. Можно и просто открыть `index.html` двойным кликом: скрипты подключены без модулей и работают по `file://`.

## Подключение Supabase

1. Создай проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query** → вставь содержимое [`database/schema.sql`](database/schema.sql) → **Run**.
3. **Project Settings → API Keys** → скопируй **Project URL** и публичный ключ (`anon` или `sb_publishable_...`).
4. Вставь их в [`js/config.js`](js/config.js):

   ```js
   supabase: {
     url: 'https://xxxxxxxx.supabase.co',
     anonKey: 'sb_publishable_...',
   }
   ```

> **Никогда** не размещай в коде ключи `service_role` или `sb_secret_...`: они дают полный доступ к базе. Публичный ключ хранить в репозитории можно — доступ ограничен RLS и RPC-функциями.

### Как защищены данные

- RLS включён, политик для клиента нет — прямые запросы к таблице запрещены.
- Запись идёт только через `record_saving(...)`, которая проверяет UUID, сумму (до 21 000 ₸), количество упаковок (до 30) и дату (от −7 до +1 дня).
- Уникальный ключ `(anon_user_id, accrual_date)` не даёт записать один день дважды.
- Чтение — только агрегаты через `get_global_stats()`. Отдельные записи наружу не отдаются.
- Если сервер недоступен, запись ждёт в очереди LocalStorage и отправляется позже.

**Ограничение:** анонимный ID из LocalStorage не является авторизацией. Его можно сбросить или подменить, поэтому глобальная статистика **не защищена от накрутки полностью**.

## Публикация на GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Source:** Deploy from a branch → **main** / **(root)** → **Save**.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/PlasticBack/`.

В корне лежит файл `.nojekyll`, чтобы GitHub Pages отдавал файлы как есть. Подойдёт и любой другой статический хостинг: Netlify, Vercel, Cloudflare Pages.

## Как считаем

| Показатель | Формула |
|---|---|
| Расходы за день | Σ (количество × цена) |
| Расходы за месяц | день × 30 |
| Расходы за год | день × 365 |
| Упаковки за год | упаковки в день × 365 |
| Объём воды | бутылки воды × 0,5 л — объём напитка, а не мусора |
| Пластиковые бутылки | Σ (количество × коэффициент) × 365 |
| Экономия | сумма дневных расходов за отмеченные дни |

Все цены, коэффициенты, пороги и эквиваленты вынесены в [`js/config.js`](js/config.js). Неутверждённые значения помечены `temporary: true`:

| Параметр | Значение | Статус |
|---|---|---|
| Кофейный стакан как пластиковая бутылка | 0 | временно, коэффициент не утверждён |
| Банка энергетика как пластиковая бутылка | 0 | временно, банка алюминиевая |
| Пороги комнаты | 0 / 1 / 366 / 1096 бутылок в год | временно |
| Абонемент в зал / кино / донер | 15 000 / 2 500 / 1 800 ₸ | временно |

Если меняешь цены, проверь лимит 21 000 ₸ в `database/schema.sql` (10 × сумма цен).

## Проверено

- Ширина экрана 360, 390, 768 и 1440 px — без горизонтальной прокрутки.
- Сохранение данных после перезагрузки страницы.
- Нулевые значения калькулятора.
- Запрет повторной отметки в тот же день, в том числе из второй вкладки и после сброса.
- Восстановление после повреждённых данных в LocalStorage.
- Запись и чтение статистики в Supabase, отказ сервера на некорректные данные.
