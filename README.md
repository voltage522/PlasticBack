# PlasticBack

**PlasticBack** — эко-финтех калькулятор для жителей Казахстана 16–35 лет. Показывает, сколько денег уходит на напитки навынос, сколько упаковки остаётся после них и сколько можно сэкономить, изменив привычки.

MVP первых трёх недель: калькулятор → итоги в стиле «Wrapped» → трекер экономии с глобальной статистикой.

## Возможности

- **Калькулятор** — вода (250 ₸), кофе (1 200 ₸), энергетики (650 ₸); ползунки 0–10, кнопки ±, мгновенный пересчёт.
- **Итоги** — расходы за день / месяц / год, упаковки за год, номинальный объём воды, потенциальная экономия, комната с четырьмя состояниями загрязнения, материальные эквиваленты.
- **Трекер** — отметка «день без покупок» (одна в календарный день), накопленная экономия, непокупленные бутылки, серия, прогресс к цели 30 дней, мини-календарь, сброс с подтверждением.
- **Без регистрации** — всё хранится в LocalStorage и восстанавливается после перезагрузки.
- **Глобальная статистика** через Supabase (необязательно). Без Supabase сайт полностью работает локально.

## Стек

HTML5, CSS3, Vanilla JavaScript (без сборки), LocalStorage, Supabase + `@supabase/supabase-js@2` (загружается с CDN, только если Supabase настроен), шрифт Manrope.

## Структура

```
PlasticBack/
├── index.html            # разметка трёх экранов, шаблон карточки, модалка
├── css/
│   ├── style.css         # дизайн-система и компоненты (mobile-first)
│   └── responsive.css    # брейкпоинты 375 / 768 / 1024 / 1440
├── js/
│   ├── config.js         # цены, коэффициенты, пороги, эквиваленты, ключи Supabase
│   ├── calculator.js     # математическая модель (чистые функции)
│   ├── tracker.js        # логика отметок, серии, сброса (чистые функции)
│   ├── storage.js        # LocalStorage: загрузка, валидация, восстановление
│   ├── supabase.js       # RPC-вызовы, таймауты, обработка ошибок
│   └── app.js            # UI-контроллер и навигация
├── assets/
│   ├── icons/            # иконки напитков, интерфейса, эквивалентов
│   └── images/           # иллюстрации комнаты (room-*.svg)
├── database/schema.sql   # таблица, RLS, RPC-функции
├── .gitignore
└── README.md
```

Слои разделены: `calculator.js` и `tracker.js` не знают о DOM и хранилище, `storage.js` — о сервере, `app.js` только связывает их с интерфейсом. Глобальный объект `window.PlasticBack` (`config`, `calculator`, `tracker`, `storage`, `api`, `app`) — точка расширения, например для будущего Telegram Web App.

## Локальный запуск

Сборка не нужна. Подойдёт любой статический сервер:

```bash
cd PlasticBack
python -m http.server 8080
# или
npx serve .
```

Откройте http://localhost:8080. Можно открыть и `index.html` двойным кликом — скрипты подключаются без модулей и работают по `file://`.

## Подключение Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query** → вставьте содержимое `database/schema.sql` → **Run**.
3. **Project Settings → API**: скопируйте **Project URL** и **anon public** key.
4. Вставьте их в `js/config.js`:

   ```js
   supabase: {
     url: 'https://xxxxxxxx.supabase.co',
     anonKey: 'eyJhbGciOi...',
     ...
   }
   ```

5. Обновите страницу → «Трекер»: блок «Глобальная статистика» покажет реальные данные.

> ⚠️ Используйте **только anon key**. `service_role` key даёт полный доступ к базе и никогда не должен попадать в клиентский код или репозиторий.

### Как устроена защита

- RLS включён, политик для клиента нет: прямые запросы к таблице `savings_records` запрещены.
- Запись — только через `record_saving(...)`: проверка UUID, суммы (0 < x ≤ 21 000 ₸), упаковок (0–30), даты (от −7 до +1 дня от текущей UTC-даты).
- Уникальный ключ `(anon_user_id, accrual_date)` + `on conflict do nothing` — повторная отправка за тот же день возвращает `duplicate` и не учитывается.
- Чтение — только агрегаты через `get_global_stats()`; отдельные записи наружу не отдаются.
- Если отправка не удалась (офлайн, таймаут), запись остаётся в очереди LocalStorage и уходит позже.

**Ограничение:** анонимный ID из LocalStorage не является аутентификацией. Его можно сбросить или подменить, поэтому глобальная статистика **не защищена от накрутки полностью**. Для усиления — Supabase Anonymous Auth, Telegram `initData`, rate limiting в Edge Functions.

Если Supabase не настроен или недоступен, калькулятор и трекер продолжают работать, а в блоке статистики выводится честное сообщение. Выдуманные цифры не показываются.

> Если меняете цены в `config.js`, проверьте лимит 21 000 ₸ в `database/schema.sql` (`10 × сумма цен`).

## Математическая модель

| Показатель | Формула |
|---|---|
| Расходы за день | Σ (количество × цена) |
| Расходы за месяц | день × 30 |
| Расходы за год | день × 365 |
| Упаковки за год | упаковки в день × 365 |
| Номинальный объём воды | бутылки воды × 0,5 л *(объём напитка, не мусора)* |
| Пластиковые бутылки | Σ (количество × `plasticBottleFactor`) × 365 |
| Экономия | Σ дневных расходов за отмеченные дни |
| Потенциальная экономия | годовые расходы × доля сценария (50 % / 100 %) |

Экономия за день фиксируется в момент отметки по текущим значениям калькулятора.

### Временные (неутверждённые) значения

Отмечены `temporary: true` в `js/config.js`:

| Параметр | Значение | Комментарий |
|---|---|---|
| `plasticBottleFactor` кофе | 0 | Стакан с крышкой не считается бутылкой до утверждения коэффициента |
| `plasticBottleFactor` энергетиков | 0 | Алюминиевая банка не является пластиковой бутылкой |
| Пороги комнаты | 0 / 1 / 366 / 1096 бутылок в год | «Чисто» / «Захламлено» / «По колено» / «Катастрофа» |
| Абонемент в зал | 15 000 ₸ | |
| Билет в кино | 2 500 ₸ | |
| Донер | 1 800 ₸ | |

## Замена иллюстраций

Иллюстрации комнаты — простые SVG-заглушки в `assets/images/room-*.svg`. Чтобы заменить их финальными:

1. Положите новые файлы (SVG/PNG/WebP, пропорции 400 × 260) в `assets/images/`.
2. При необходимости обновите пути `image` в `config.room.states`.

Логику менять не нужно. Если файл не загрузится, вместо него появится CSS-заглушка.

## Публикация

Сайт статический — подойдёт любой хостинг.

- **GitHub Pages:** запушьте репозиторий → Settings → Pages → Deploy from branch → `main` / root (если `PlasticBack/` — корень репозитория).
- **Netlify:** перетащите папку `PlasticBack` на app.netlify.com/drop или подключите репозиторий (build command пустой, publish directory — `PlasticBack`).
- **Vercel:** `npx vercel` в папке проекта, framework preset — *Other*.

Anon key в `config.js` публичен по замыслу: доступ ограничен RLS и RPC-функциями.

## Чек-лист проверки

- [ ] Ширины 360, 390, 768, 1440 px: нет горизонтального скролла, итоговая панель не перекрывает контент.
- [ ] Все ползунки на 0 → «0 ₸», экран итогов показывает состояние «Чисто», кнопка трекера неактивна.
- [ ] Значения ползунков и прогресс трекера сохраняются после перезагрузки.
- [ ] Повторная отметка в тот же день невозможна (в том числе из второй вкладки и после сброса).
- [ ] Повреждённый JSON в `localStorage['plasticback:v1']` → данные восстанавливаются, показывается уведомление.
- [ ] Без настроек Supabase всё работает, в блоке статистики — сообщение о неподключённой базе.
